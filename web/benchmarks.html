Methodology

What the numbers actually mean

Every metric answers a specific product-claim question. We run the same backbone (Qwen2.5-VL-7B-Instruct) both ways — Bernoulli reads single-token logits at the answer position; Generative asks in natural language and parses the completion. BGE-m3+LR embeds the input and fits per-task logistic regression on labeled data (500 examples).

Metrics

  • Accuracy, macro-F1 — top-1 label match.
  • ECE (10 bins) — Expected Calibration Error, JevBench convention. Lower is better; 0 is perfect calibration.
  • Brier — mean squared error of top-class probability.
  • NLL — negative log-likelihood of the gold label under the predicted distribution. The headline calibration metric; dramatically worse for the point-mass outputs of a text-and-parse pipeline.
  • Stability (reorder, reword) — fraction of examples whose top-1 is unchanged under option permutations and up to three paraphrased question stems. Binary skips reorder (Yes/No order is semantic, not positional).

Baselines

  • Bernoulli over HTTP against the running /v1/decide server. Reverse debias on choice; no debias on binary (Yes/No are semantic — reversing their order changes meaning, not position).
  • Generative over HTTP against the same server's /v1/generate. Same backbone, same prompt framing, parsed completion → point mass on parsed answer or uniform on parse failure.
  • BGE-m3 + LR — embed inputs with BAAI/bge-m3 (CLS pooling, L2-normalise), train scikit-learn's LogisticRegression on 500 labeled training examples (seeded shuffle for class balance). Honest baseline for "could we have used embeddings?"
  • DeBERTa-v3-zeroshot — the zero-shot encoder column is missing from today's tables. CPU latency on 4-way+ is pathological; GPU is held by the Bernoulli server. Needs a shared-GPU setup or an overnight CPU batch.
Honest caveats

What this run is not

These numbers hold the calibration thesis across nine benchmarks. The caveats below are known today and disclosed up front; most are time-and-engineering rather than fundamental.

Known limitations in this snapshot

  • N=100 eval examples per benchmark. Numbers in a 5-point band can swing 2–3 points at N=500. Direction holds; precision doesn't. A higher-N pass is pending (hours of GPU, not days).
  • No DeBERTa-v3-zeroshot column. The strongest open zero-shot encoder is missing — CPU latency is pathological on 4-way+ (hours per benchmark), and GPU is held by the Bernoulli server. Fix is either shared-GPU scheduling or an overnight CPU batch. Does not change the calibration gap between Bernoulli and Generative, but it's the main gap in the "did we need an LLM?" story.
  • Banking77 reorder stability = 0.13. With 77 options we exceed the 26-letter alphabet so bernoulli/chunked.py splits into 3 chunks of ≤26 labels and softmaxes globally. The top-1 therefore shifts when the chunks change — architectural, not a bug. Cross-chunk debias is parked. Any Banking77 citation needs the chunked-stability footnote.
  • XSTest unsafe_recall = 0.36. Bernoulli's 0% false-refusal is a product-grade property, but it under-flags actually-unsafe prompts. For a complete guardrail you want Bernoulli as the first-pass "don't over-refuse" gate paired with an escalation path (human-in-loop or a tuned classifier) for the long tail.
  • CLINC150-OOS OOS recall ≈ 0.52 for Bernoulli. Coin flip on the "none of these" story. Likely prompt-framing + stem rewording; investigation pending.
  • Dev-tier backbone. Numbers are from Qwen2.5-VL-7B-Instruct on an AWS g5.xlarge (A10G 24GB). The production step-up to Qwen2.5-VL-32B-Instruct-AWQ on g6e.xlarge (L40S 48GB) is parked on AWS capacity.
  • JevBench numbers are self-reported. Our 2026-10-08 run through the official harness is pending submission to benchmarkheaven.com/jev-models — the Benchmark Heaven FIFO queue has not yet published a listing. Reproduce locally from results/2026-10-08.md; this page updates with the official rank + external link once the entry posts.
  • arXiv post-cutoff dataset was regenerated 2026-10-07. 200 papers across 4 categories, publication dates 2026-09-18 to 2026-10-06 — well after any plausible Qwen2.5-VL training cutoff. On this provably-unseen corpus, Bernoulli hits 0.95 acc with NLL 10.7× better than Generative. The anti-contamination claim is backed by real data, not a placeholder. If the backbone is swapped to a later-cutoff model, make_dataset.py re-runs with the updated cutoff.
