Privacy Policy — Bernoulli for Terms

Last updated: 2026-10-29

Summary

Bernoulli for Terms is a Chrome extension that reads a terms-of-service page you're looking at and sends the text to a configurable "decide" endpoint, which returns a scorecard against twelve calibrated questions. No usage metrics, telemetry, or analytics are collected. The extension author receives no information from your use of the extension unless you have configured it to call an endpoint the author operates.

What data is read

When you open the side panel on a page, the extension reads from the current tab:

  • The page's URL
  • The page's title
  • The visible text content, extracted via Mozilla Readability (falls back to raw document.body.innerText if Readability can't find article content)
  • Any text you have highlighted at the moment you open the panel (optional; used only if you choose "Analyze selection")

This happens via chrome.scripting.executeScript on the tab you're currently viewing. The extension reads the page only when you open the panel; it does not run in the background, does not watch what you browse, and does not inject any always-on content scripts.

What data is sent, and where

The URL, title, extracted text, and (optionally) selection are combined into a single state payload and sent to the "Decide endpoint" you configure in Settings via an HTTPS POST /v1/decide request. The default endpoint is:

  • https://bmock.nuwire.dev — a public mock service that returns canned responses and does not persist your data

You can change this to any endpoint you trust. The project author also operates a dev-tier production endpoint at https://bernoulli-api.nuwire.dev; see its API reference for its own operational scope.

You are responsible for choosing an endpoint you trust. The extension does not call any other servers.

What data is stored on your machine

Two Chrome storage areas:

  • chrome.storage.sync (syncs across your Chrome profile): your endpoint URL, API token, detection-sensitivity setting, cache-enabled flag, cache TTL.
  • chrome.storage.local (this device only): a per-URL cache of scorecard results (24h default TTL, configurable), and a one-time "disclaimer acknowledged" flag.

The cache stores: the scorecard response from the endpoint, the URL you analyzed, a cheap content hash (text length + first 500 + last 500 characters) to detect page changes, and a timestamp. Clear it anytime via Settings → Clear cached results.

Nothing in storage is sent anywhere else.

Permissions explained

PermissionWhat it's for
activeTabRead the current tab when you open the panel
scriptingInject the extraction + signal-collection script into the current tab
storageStore settings + cache locally
sidePanelOpen the side panel UI
host_permissions: https://*.nuwire.dev/*Call the default and production endpoints
optional_host_permissions: <all_urls>If you configure a non-nuwire endpoint, Chrome asks for permission to call it. Granted per-host, revocable at chrome://extensions.

No tracking

Bernoulli for Terms does not use analytics services (no Google Analytics, no Mixpanel, no Sentry), does not phone home, and does not log usage data to the extension author.

Children

The extension is not intended for use by children under 13.
